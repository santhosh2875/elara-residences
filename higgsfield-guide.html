Six views of one building

Work down the page: one master image, five more angles of the same building, then one short clip per image. Each card turns green by itself when its file is in assets/views.

These fill into the prompts below. The words on the website itself are set in config.js.

1 Make the master image

Text to image. This one picture decides how every other view looks, so retry it until you like the building.

2 Five more angles of the same building

Image to image. Upload the master image as the reference every single time. If a view comes back with a different-looking building, regenerate that image now: it is far cheaper to fix here than after animating.

3 Animate each image

Image to video. Only animate stills you are happy with, because this step is where the credits go.

Upload the still as the start frame and leave the end frame empty. The clip will have a small jump where it restarts; once your clips are in the folder, that jump can be blended away without spending any credits.

4 Put the files in the site

Save every download into assets/views with exactly these names. Stills can be JPG, PNG or WebP. Then open the website and reload.
